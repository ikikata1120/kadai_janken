# ①課題名
叩いてかぶって、ジャンケンポン！

## ②課題内容（どんな作品か）
- コンピュータとジャンケンして、ジャンケンに勝ったらハンマーで叩く。ジャンケンに負けたらヘルメットで防ぐゲームです。
- 今回はジャンケン後、3秒以内に叩く/防ぐことができなかった場合、コンピュータに防がれる/叩かれるような仕様にしました。

## ③アプリのデプロイURL
デプロイしている場合はURLを記入（任意）

## ④アプリのログイン用IDまたはPassword（ある場合）
- ID: 無し
- PW: 無し

## ⑤工夫した点・こだわった点
- 娘に、「あっちむいてほい！」と「叩いてかぶって、ジャンケンポン！」のどっちがいい？と聞いたところ、「叩いてかぶって、ジャンケンポン！」がいい！と言われたので、作成しました。
- 叩いたり防いだりする時間制限を設けることで、ゲーム性を高める工夫をしました。
- ⇒ここはAIにたくさん助けてもらいました。タイマー設定や時間切れ後の挙動など・・・


## ⑥難しかった点・次回トライしたいこと（又は機能）
- 毎回、CSSで苦労しています。特に、画像の高さや位置を揃えることに苦戦しています。
- ジャンケン後の秒数を変えることで、「初級・中級・上級」などの設定ができると面白いかな～。と思っています。
